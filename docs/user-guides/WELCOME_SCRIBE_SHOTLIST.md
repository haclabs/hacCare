# Scribe Shot-List — Welcome to hacCare (Part 1)

Recording plan for the Part 1 walkthroughs. Each entry below becomes one Scribe.

**How to publish a finished Scribe:**
1. In Scribe, open the recording → **Share** → **Embed** → copy the iframe `src` URL.
2. In hacCare, go to **Help & Docs** → **Walkthroughs** → **Add Walkthrough**.
3. Paste the URL, set the title and category exactly as listed below, save.

Adding walkthroughs requires a super admin account.

**Before recording:**
- Use a throwaway instructor account, not your own — the invite and first-login screens only appear once per account.
- Have an administrator create the test account so you can capture the real invitation email.
- Assign the test account to **two or more programs** so the program chooser appears (Scribe 2).
- Use a clean browser profile with no saved hacCare session.
- Blur or use fake data for any name, email address, or student information.

## Scribe 1 — Activating Your hacCare Account

**Category:** Getting Started
**Starts at:** the invitation email in your inbox
**Ends at:** signed in, program workspace visible

| # | Screen | Action | Callout text |
| --- | --- | --- | --- |
| 1 | Inbox | Show the email from `noreply@haccare.app`, subject "Welcome to hacCare — Set up your account" | Check junk mail if you don't see it. Ask your admin to resend if it's missing. |
| 2 | Email body | Click the set-up button | |
| 3 | Activation page | Click **Activate Account** | Nothing happens until you click — this protects the link from email security scanners. |
| 4 | Password page | Type a password | At least 8 characters, one uppercase letter, and one symbol. |
| 5 | Password page | Type it again in the confirm field | |
| 6 | Password page | Submit | You're signed in automatically — no need to return to the login page. |
| 7 | Program workspace | Land on the workspace | |

> If the link is dead, capture the "expired" state too — it's the single most common support question. Worth a short Scribe of its own if it's easy to reproduce.
