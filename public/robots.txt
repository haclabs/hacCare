# One group for every crawler. A bot obeys only the most specific group that
# names it, so adding a "User-agent: Googlebot" group here would make Google
# ignore every Disallow below. Add per-bot groups only to block a bot outright.
#
# /login is left crawlable on purpose: it carries a noindex tag, which
# Google can only see if it is allowed to fetch the page.
#
# AI search crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, …) are
# deliberately allowed so hacCare can appear in AI-generated answers.
